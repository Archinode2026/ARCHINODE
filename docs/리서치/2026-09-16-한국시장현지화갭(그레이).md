# 한국 인테리어·건축 플랫폼 시장 현지화 갭 분석 (2026-09-16, 그레이)

조사 방법: 웹 검색(2026-09-16 기준, 실시간) + 리포 코드 검토(`index.html` 푸터, `products/view.html`, `docs/ARCHINODE 규정집.md`). 아키프로덕트 비교가 아니라 **한국 국내 플랫폼**(오늘의집·하우스텝·집닥·한샘몰·LX Z:IN·네이버 스마트스토어·KIRA) 대비 ARCHINODE의 "한국에서 당연시되는데 없는 것" 조사.

### 아키프로덕트 현황 — 어떻게 구현하고 있나
해당 없음(이번 조사는 국내 플랫폼 대상). 아키프로덕트 자체 비교는 `.claude/skills/gray-benchmark/SKILL.md`에 기존 프로필 있음 — 요약하면 아키프로덕트도 자체 결제(700+ 브랜드 샵)·리뷰는 약하고, 리드("Request Info") 중심이라 ARCHINODE의 리드 모델과 구조적으로는 가깝다. 단, 아키프로덕트는 **유럽 시장**을 겨냥해 한국 특유의 관행(카카오·평형·에스크로 표시)이 애초에 필요 없다 — 그래서 이 갭들은 "아키프로덕트도 안 하는데 한국은 한다"는 유형이 많다.

### 업계 동향 — 국내 플랫폼 조사 결과 (2026-09-16 검색 기준)

**오늘의집(버킷플레이스)**

**집닥(Zipdoc)**

- 업체용 앱 "집닥 파트너스" 별도 운영.

**한샘몰 / LX Z:IN**

[출처: LX Z:IN 매장찾기](https://www.lxzin.com/zin/exhibition/), [한샘 사업영역](https://company.hanssem.com/about/business), [LX하우시스 B2B 카탈로그](https://www.b2bzincatalog.com/)
- 시사점: 대형 건자재사는 "일반 소비자몰"과 "B2B 딜러 카탈로그"를 아예 분리된 사이트로 운영 — ARCHINODE의 브랜드 페이지 1개로 두 청중을 함께 상대하는 구조와 대비됨.

- 사업자 정보: `index.html` 1102~1105행 푸터에 상호·대표·사업자등록번호(640-03-02879)·주소·이메일 표시됨(공유 푸터이므로 전 페이지 적용 추정). **통신판매업 신고번호·구매안전서비스 표시는 없음** — 위에서 짚었듯 직접 판매를 안 하니 의무 자체가 없을 가능성이 크나, 최종 확인은 법무(node-navy) 몫.

- 평형/㎡, 온돌 등 한국 건축 특화 필드: `products`/`brands` 스키마에 확인 안 됨(유럽 브랜드 카탈로그 원본이 mm/cm 위주라 애초에 평형 개념이 없을 가능성 높음).
