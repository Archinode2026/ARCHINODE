# 기능 갭 우선순위 — 그레이 조사 2건 종합 (2026-09-16, 노드-실버)

**바탕 자료**: `docs/리서치/2026-09-16-글로벌플랫폼기능갭(그레이).md`(31개 항목) · `docs/리서치/2026-09-16-한국시장현지화갭(그레이).md`(17개 항목). 그레이는 "무엇이 있는지"만 조사했고, 이 문서는 그걸 순서로 바꾼 것이다. **이 문서에 새로 적은 판단(사슬·난이도·순위)은 코드 재검토 없이 그레이 보고서 + 기존 CLAUDE.md·규정집·작업일지 대조만으로 낸 것**이다. 그레이가 "확인 못 함"이라 적은 항목은 이 문서에서도 실측하지 않았다 — 필요하면 블랙(코드)·브론즈(실동작)에 별도로 시켜야 한다.

---

## 지금 당장 결정할 것 3가지

1. **GA4를 켤 것인가(`GA_ID` 값 발급·입력)** — 한 줄로 끝나는 설정이지만 이게 없으면 "브랜드 애널리틱스"(그레이 글로벌#15, HIGH)도 "매거진 트래픽 규모 파악"(글로벌#5)도 둘 다 시작을 못 한다. 결정이라기보다 실행이지만 **한울님만 할 수 있는 손(Analytics 계정 생성)**이라 여기 올린다.
2. **카카오톡 채널 상담 버튼을 지금 넣을 것인가** — 그레이가 한국#1(HIGH)로 꼽았는데, 규정집 1-7("좋아요는 지금, 댓글·채팅은 나중")과 겹치는지 애매하다. "브랜드-전문가 프로젝트 채팅"과 "방문자→운영팀 카카오 상담"은 성격이 다르다고 보이지만, 1-7을 정한 게 한울님이라 실버가 임의로 "이건 다르다"고 넘기지 않는다.
3. **이커머스(카트·결제·가격노출) 제안을 규정집 안건으로 새로 올릴지, 아니면 "이미 1-1·1-3에 답이 있다"고 보고 안건화 자체를 안 할지** — 그레이가 8개 벤치마크 중 다수가 하는 것이라 짚었지만, 규정집 1부가 이미 "직접 판매 안 함·가격 비노출"을 정했다. 안건으로 새로 올리면 논의가 다시 열리는 것이고, 안 올리면 "현행 유지"로 조용히 넘어가는 것 — 어느 쪽이든 한울님이 알고 정할 일이지 실버가 조용히 덮을 일은 아니다.

## 작업 사슬 (먼저 되어야 다음이 의미 있는 것)

체인마다 **먼저 되어야 하는 것 → 이게 막고 있는 것**을 적는다. "앞이 없음"(전제조건 자체가 없어 지금 시작 가능)과 "앞을 못 찾음"(정보가 없어 순서를 못 정함, 그레이도 "확인 못 함"이라 한 항목)을 구분해 적는다.

1. **GA4 설정(한울님, `GA_ID` 발급) → 트래픽 실측(글로벌#5) → 브랜드 애널리틱스 대시보드(글로벌#15) 설계 범위 확정.** GA4 없이 브랜드 애널리틱스를 만들면 "무엇을 보여줄지"조차 못 정한다(조회수를 Firestore에 직접 쌓을지 GA4 이벤트로 뺄지가 골드 설계의 첫 갈림길). — 앞이 없음(GA_ID는 지금 당장 발급 가능, 코드 작업 아님).
2. **제품 데이터가 늘어남(그린의 브랜드 유치 성과) → 고급 필터(글로벌#1) → AI 시맨틱 검색(글로벌#2).** 그레이도 "필터 없이 AI 검색은 순서상 뒤"라고 명시했다. 지금 필터를 만들어도 대분류 10개·정적 브랜드 몇 개뿐이면 필터할 게 없다 — 앞을 못 찾음이 아니라 **앞이 아직 안 쌓인 것**(브랜드 영업 병목, node-green 영역).
3. **4b 공개 리드/견적 폼(법률 검토 대기, 작업일지 A-0에 이미 있음) → 정식 RFQ 플로우(글로벌#12) → 자동 견적 산출(한국#3).** 지금 순서가 뒤바뀌면 "접수창구도 없는데 견적 자동계산기부터 만드는" 꼴이 된다. — 앞이 있고 이미 알려진 병목(변호사 확인 5건 미해결)이지 새로 발견한 게 아니다.
4. **브랜드 20~50개 확보(그린) → 리뷰/평점(글로벌#6·한국#4) → 디자이너 프로필(글로벌#20) → 어워드 프로그램(글로벌#21).** 그레이 자신도 리뷰·디자이너 페이지를 "브랜드 수 확보 후가 현실적"이라 적었다. 지금 리뷰를 열면 리뷰 母수가 너무 적어 "썰렁한 게시판"이 브랜드 신뢰를 오히려 깎을 수 있다.
5. **딜러 정보 구조화(공인 배지 필드 추가, 소규모) → 지역 딜러 지도 검색(한국#2).** 지도 UI 자체보다 "이 딜러가 어느 지역인지" 데이터가 구조화돼 있어야 하고, 지도 API 키 발급(한울님 인프라, 비용 발생 가능)이 별도로 필요하다.
6. **매거진 자동 발행 파이프라인 정상화(작업일지 A-0, 한울님 손 필요 — 리포 밖) → 트레이드페어 콘텐츠 연동(글로벌#22·한국#14).** 지금 매거진 파이프라인 자체가 백지 사고 재발 위험을 안고 있는데 새 콘텐츠 축을 얹으면 같은 사고가 한 곳 더 생긴다.

## 지금 진행 중인 작업과의 우선순위 — 추천 + 이유 + 트레이드오프

**추천**: 이 신규 기능 항목들은 전부 작업일지 **B절(제품 기능)**로 넣고, **A절(검수대장 결함 수정·어드민 개편 잔여)을 그대로 먼저** 간다. 2026-09-12 한울님 결정("운영 체계 먼저, 제품 기능 다음")이 아직 뒤집힌 적이 없고, 검수대장에는 A-012(영업자료 폴더 개인정보 노출)·A-046(카테고리 제품목록 색인 오류로 콘솔 오류·빈 화면) 같이 **지금 방문자에게 이미 영향을 주는** 항목이 대기 중이다. 새 기능이 이걸 밀어내면 원칙 2(빈 곳 없이)·원칙 4(브랜드에게 보여줄 상태)에 어긋난다.

**이유**: 규정집 1-12절이 "운영 체계 먼저"를 정할 때 근거로 든 것과 같다 — 결함이 쌓인 채 새 기능을 얹으면 검수 부담이 두 배로 늘고, 이미 A-031(브론즈 병렬 호출로 실데이터 오염) 같은 사고가 "여러 일을 동시에 벌였을 때" 났다.

**트레이드오프(잃는 것)**: A절을 먼저 가면 이번에 발견한 HIGH 항목들(고급 필터·브랜드 애널리틱스·리뷰)의 착수가 그만큼 늦어진다. 특히 브랜드 애널리틱스는 "브랜드가 한국 시장 반응을 실시간 확인"이라는 CLAUDE.md 핵심가치와 실제 구현 사이 간극이 크다고 그레이가 지적했다 — 이 간극이 브랜드 재계약·영업 피칭에 실제로 영향을 줄 수 있어, 마냥 뒤로 미루면 손해가 누적된다.

**절충안(한 줄)**: "가" 갈래 4개(온돌표시·딜러배지·무드보드·뉴스레터 세그먼트)는 전부 작은 추가라 A절 작업 사이 여유가 날 때 끼워 넣어도 위험이 적다. 다만 이것도 **A절을 밀어내면서까지 먼저 하라는 뜻은 아니다** — 최종 배치는 한울님 결정.
