# ARCHINODE 벤치마크 분석 — 글로벌 8개 플랫폼 갭 분석 (2026-09-16, 노드-그레이)

## 조사 방법 및 한계 고지

Archiproducts·Architonic·ArchDaily·Dezeen·Houzz(Pro)·1stDibs·Material Bank·Pinterest for Business 8개 대상을 실시간 WebSearch/WebFetch로 조사했다(조사일 전부 2026-09-16). Archiproducts.com·Architonic.com은 자바스크립트 렌더링 SPA라 WebFetch 직접 열람이 대부분 실패했고, 검색 스니펫·공식 서브도메인 페이지(business.archiproducts.com, bim.archiproducts.com 등)로 교차 확인했다. **로그인이 필요한 화면(브랜드 대시보드 내부, 가격표 등)은 이번 조사로 확인 못 함** — 필요하면 브론즈(node-bronze)의 실브라우저 로그인 검증을 권한다.

ARCHINODE 현재 상태는 이번 세션에서 직접 코드 검토(grep)한 결과다: `categories/*.html`에 필터 코드 없음, `admin/js/view-dashboard.js`는 카운트 카드 9개 + 최근 활동 로그뿐(조회수/전환 통계 없음), `brand-portal/dashboard.html`의 "견적 요청"은 어드민이 수동 등록하는 리드 타입 라벨일 뿐 실제 견적서 생성·품목관리 기능 아님, `brands/view.html`은 `koreanDealer` 필드를 표시하지만 "공인 딜러" 인증 배지 UI는 코드에서 확인 안 됨, `admin/newsletter-subscribers.html`+`notify-subscribers.html`은 수동 발송 구조로 보임(자동 드립 캠페인 코드 확인 못 함).

**CRITICAL은 없음.** ARCHINODE는 아직 브랜드/제품 데이터 자체가 얕아서(정적 브랜드 3개 수준, 로드맵상 동적 시스템은 준비됨) 위 갭들이 "지금 당장 사업을 막는" 수준은 아니다. 다만 다음 4개는 **HIGH**로 판단한다 (근거: 8개 벤치마크 중 최소 3곳 이상에서 핵심 기능으로 확인됨 + ARCHINODE 핵심가치 문서와 직결):

1. **고급 필터(#1)** — 검색 없이는 발견성 자체가 성립 안 함
2. **브랜드 애널리틱스(#15)** — CLAUDE.md가 명시한 핵심가치("반응을 실시간 확인")와 실제 구현의 간극이 가장 큼
3. **리뷰/평점(#6)** — 신뢰 격차를 메우는 유일한 동료검증 장치, 단 도입 타이밍은 브랜드 수 확보 후
