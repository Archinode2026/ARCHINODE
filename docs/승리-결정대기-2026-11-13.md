# 승리님 결정 대기 — 2026-11-13 새벽

주무시는 동안 **A-503 ~ A-511** 아홉 건을 처리하고 브론즈를 **34차** 돌렸습니다.
푸시 대기 **8개**. 검사는 27개에서 **30개**로 늘었고 전부 통과합니다.

아래는 **승리님만 정할 수 있는 것들**입니다. 급한 순서로 적었습니다.

---

## 0. 먼저 — 코드가 아니라 손이 필요한 것 (결정 아님, 작업입니다)

브론즈 34차가 토큰 없는 REST 로 라이브에서 다시 쟀습니다. **31차와 같습니다.**

| | 상태 | 근거 |
|---|---|---|
| Firestore 규칙 | **올라감** | 비로그인 `settings` 읽기가 403 |
| **Storage 규칙** | **안 올라감** | `products-specs/` 가 공개 폴더와 같은 응답 |
| **마이그레이션 3건** | **안 됨** | 승인 브랜드 3건의 `email`·`contactName`·`phone` 이 **토큰 없이 그대로 읽힙니다** |

화면 HTML 에는 안 나옵니다(0건). **REST 로 직접 읽으면 나옵니다.** 담당자 개인정보라
먼저 처리하시는 게 좋겠습니다. 절차는 세 문서에 있습니다:
`docs/마이그레이션-담당자연락처-2026-11-12.md` → `…-리드-내부기록-…` → `…-자료파일-…`

`deploy.ps1 -Rules` 는 firestore 와 storage 를 **따로** 올립니다. 배포 로그에
노란 「storage 게시 실패」 상자가 떴는지 봐 주세요(전에도 GCP 권한 403 으로 실패한 적이 있습니다 — A-315·A-350).

## 1. 전화번호 — 법이 요구하는데 제가 모르는 값입니다 ★

전자상거래법 제13조제1항은 **상호·대표자·주소·전화번호·이메일·사업자등록번호·통신판매업 신고번호**를
사이버몰에 표시하도록 합니다. 신고증에서 신고번호(제2026-안양동안-0318호)와 기관(안양시 동안구청)을
빼내 **234벌의 푸터와 약관·처리방침 국·영문에 전부 넣었습니다**(A-503).

**전화번호만 비어 있습니다.** 신고증에는 적혀 있지 않고 사이트 어디에도 없습니다.
알려 주시면 같은 자리 다섯 꼴에 한 번에 넣겠습니다. 없는 값을 제가 지어낼 수는 없습니다.

---

## 2. 디지털 상품을 올리실 때 필요한 것 ★

A-504 로 **맛보기(`previewUrl`)가 없는 상품은 구매 단추가 서지 않습니다.**
전자상거래법 제17조제2항제5호가 디지털 콘텐츠의 청약철회를 제한하려면
「시험 사용 상품 제공 등」의 조치를 **함께** 하도록 정하기 때문입니다(A-502 검토 결과).

상품마다 **맛보기 파일**을 준비해 주세요 — 목차나 앞 몇 장이면 됩니다.
넣는 자리는 `digital-products.html` 맨 위 주석에 틀로 적어 뒀습니다.

그리고 두 가지를 제가 넣지 못했습니다:

- **공식 PayPal 마크** — PayPal 브랜드 키트에서 받은 이미지를 써야 합니다. 받아서 주시면 이동 단추에 달겠습니다.
- **공정위 통신판매사업자 조회 링크** — 주소 형식을 확인하지 못해 234개 페이지에 깨진 링크를 심을 수 없어 미뤘습니다. 확인되면 결제 화면에만 먼저 달겠습니다.

대신 결제 직전 화면에 **상호·대표자·사업자등록번호·신고번호·주소·이메일**을 한 번 더 보여 주고,
**이동할 PayPal 주소를 글자로** 보여 주고, **주소창이 `paypal.com` 인지 수취인이 비비들리바이브인지
확인하라고 먼저 말합니다**(A-505). 피싱 사이트가 못 채우는 칸은 로고가 아니라 **대조할 수 있는 숫자**입니다.

## 3. 약관 — 아직 비어 있는 조항들

A-502 의 법령 대조 검토가 **일곱 항목이 빠졌다**고 알려 왔습니다(제13조② 계약 전 고지) —
청약철회 기한·방법·효과, 환불 절차, 지급 시기, 기술적 사항, 분쟁 처리 절차, 약관 확인 방법.
초안은 `docs/약관-청약철회조항-초안-2026-11-12.md` 에 있고 **제가 `terms.html` 에 넣지 않았습니다** —
법적 문서라 승리님 검토 뒤에 넣는 것이 맞다고 봤습니다. 말씀 주시면 바로 넣겠습니다.

상품을 올리기 **전에** 들어가야 합니다.

## 4. 편집 판단이 필요한 것

- **`brand-guide.html` 은 한국어로 봐도 본문이 영어입니다.** 머리글에 `data-ko` 가 없고 본문도 영어뿐입니다.
  갓 입점한 **유럽 브랜드**를 위한 글이라 일부러 그러신 것 같은데, 맞다면 그대로 두겠습니다.
- **목록 카드 제목과 글 안 제목이 다른 글 18건** — 어느 쪽이 정본인지는 편집 판단입니다(11-12 에서 이어집니다).
- **검색 결과 페이지를 만들지** — 지금 검색은 12건까지 보여 주고 「전체 N건 중 12건, 더 좁혀 보세요」라고
  말합니다(A-509). 결과 페이지가 없어 「더 보기」를 걸 곳이 없습니다. 만들 생각이 있으시면 「전체 보기」로 바꾸겠습니다.
