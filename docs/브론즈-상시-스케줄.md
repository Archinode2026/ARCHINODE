## Cowork 스케줄 등록 (한울님, 1분)

- 주기: **2시간마다** (야간 포함. 브론즈는 라운드마다 10~40분)
- 작업 폴더: `C:\이한울 작업 공간\ARCHINODE\ARCHINODE\ARCHINODE\ARCHINODE`
- 프롬프트(그대로 복사):

```
아키노드. 지휘 창으로서 부재중 사다리 「다」 단을 한 라운드만 돌려라.
1) docs/브론즈-진행상황/ 에서 오늘 날짜 파일(없으면 만든다)의 마지막 라운드 번호를 읽고 다음 번호로 시작한다.
2) 0단계: git log -1 커밋이 라이브에 반영됐는지 tools/deploy.ps1 -NoPush 로 대조. 다르면 멈추고 그 사실만 기록.
3) 로그인이 되면(Claude in Chrome 에서 admin/dashboard.html 이 리다이렉트 없이 열리면) R1~R4·R7 중 진행상황 파일에서 가장 오래 안 돈 라운드를, 안 되면 R5·R6 변형(아직 안 본 페이지·다른 폭·배율 조합)을 node-bronze 규칙대로 돌린다. Firestore 쓰기는 [테스트-브론즈] 표시가 가능한 여정에서만, 삭제 금지.
4) 발견한 결함은 로그인이 되면 어드민 > 검수관리 탭에 검토대기로 등록, 안 되면 docs/검수대장.md 에 A-### 로 추가(재발견은 이력에만).
5) 진행상황 파일에 한 줄(라운드·시각·통과/실패·요약·만든 테스트 데이터) 추가하고 docs/작업일지.md 이력에도 한 줄. 커밋(경로 지정)·push 는 지휘 창 규칙대로(문서만이면 push 까지).
6) 한울님께 묻지 마라. 막히면 건너뛰고 기록한다. 보고는 표 하나 또는 다섯 줄.
```
