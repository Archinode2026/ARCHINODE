# 작업지시서 — 7b: 입점 신청 유입경로 자동 추적 (`?ref=`)

- **낸 사람**: 지휘 창 (26.09.14 아키 #1) — 규정집 1-13에서 "복귀 후"로 미뤄둔 항목, 한울님 2026-09-14 착수·배포 승인
- **하는 사람**: node-white (Agent 도구 직접 호출 — 한울님 부재, 실행창 없음)
- **push·배포하지 않는다. 커밋(경로 지정)까지, 「배포 준비됨」.**
- 규칙 변경 없음(아래 확인 — `firestore.rules`의 `brands` create는 `hasOnly()` 없이 `brandName`·`email` 존재만 확인하므로 필드 추가가 막히지 않는다).

## 배경

지금 브랜드가 어떻게 ARCHINODE를 알았는지는 신청서의 수동 드롭다운(`referral` — Search Engine/Social Media/... 자기가 고르는 값)뿐이다. 실비아 콜드메일·전시회·매거진처럼 **우리가 보낸 링크**를 통해 왔는지는 기록이 없다. 이 단계는 신청 페이지 주소에 `?ref=값`이 붙어 있으면 그 값을 자동으로 붙잡아 신청서 제출 때 같이 저장한다. 예: `list-your-brand.html?ref=silvia-batch1`, `?ref=milan-2026`.

## 고칠 것

**1. `list-your-brand.html` — ref 캡처 + 저장**
- 페이지 로드 시 `URLSearchParams(location.search).get('ref')`를 읽는다. 값이 있으면 `sessionStorage.setItem('archinode_ref', 값)`에 저장(사용자가 링크를 열고 바로 신청서를 안 채워도 같은 세션 안에서 유지되도록). 값이 없으면 `sessionStorage`에 이미 있는 값을 그대로 쓴다(덮어쓰지 않음).
- 폼 제출부(588줄 부근 `db.collection('brands').doc(uid).set({...})`)에 필드 추가: `referralSource: sessionStorage.getItem('archinode_ref') || null`. 기존 `referral`(수동 드롭다운) 필드는 그대로 둔다 — 이름이 비슷하니 헷갈리지 않게 코드에 한 줄 주석으로 "referral=수동 선택, referralSource=?ref= 자동 캡처"를 남긴다.
- `ref` 값은 영문·숫자·하이픈만 허용하도록 정규식으로 한 번 걸러서 저장(`/^[a-zA-Z0-9-]{1,40}$/` 안 맞으면 무시) — 주소창 값이라 그대로 Firestore에 넣지 않는다.

**2. 어드민 브랜드 상세 — 표시만**
`admin/dashboard.html` 636줄 `Referral` 표시 줄 바로 아래에 한 줄 추가:
```html
<div class="detail-row"><div class="detail-label">Referral Source</div><div class="detail-value">${escapeHtml(b.referralSource || '-')}</div></div>
```
그 이상의 통계·필터 화면은 범위 밖(다음에 필요하면 별도 지시).

완료 조건: `list-your-brand.html?ref=test-01`로 들어가 신청서를 제출하면 저장된 문서에 `referralSource: "test-01"`이 있고, 어드민 브랜드 상세에 "Referral Source: test-01"이 보인다. `?ref=` 없이 들어가 제출하면 `referralSource: null`.

## 하지 말 것

- `git add -A` 금지 — `list-your-brand.html`, `admin/dashboard.html` 경로 지정.
- `admin/dashboard.html`은 200줄 이상 바뀌는 큰 파일 — 이번 변경은 한 줄 추가뿐이라 Edit로 되지만, 다른 곳을 같이 고치지 말 것.
- UTM 파라미터(`utm_source` 등) 전체 체계로 확장하지 않는다 — `ref` 하나만, 다음 단계 아님.
- 기존 `referral`(수동 드롭다운) 필드·옵션을 건드리지 않는다.

## 검증

- node-black 필수, CRITICAL 0.
- 로그인 없이 되는 확인(신청서 제출·필드 저장)은 화이트가 `[테스트-화이트]` 표시를 단 값으로 실측 가능하면 하고, 어드민 화면 표시 확인은 로그인 정보 없으면 "확인 못 함"으로 남겨 브론즈에 넘긴다.
- 정규식 필터 확인: `?ref=<script>` 같은 값이 무시되는지 한 번 시험.
