# 작업지시서 — 어드민 언어 통일 + 한/영 전환 버튼 (검수대장 A-035, 한울님 직접 발견)

- **낸 사람**: 지휘 창 (26.09.12 아키노드 #1)
- **하는 사람**: node-white (Agent 직접 호출 — PWA 지시서 커밋 뒤에 착수, 같은 파일을 동시에 만지지 않는다)
- **push·배포하지 않는다. 커밋(경로 지정)까지, 「배포 준비됨」.** 규칙 변경 없음 · 공개 페이지 변경 없음.

## 배경 (처음 보는 사람용)

한울님이 한국어로 어드민을 쓰다가 사이드바 「접수 > 자문 요청」을 누르자 **영어 페이지**로 바뀌었다. 별도 어드민 페이지 5개(`consultations`·`trend-submissions`·`newsletter-subscribers`·`notify-subscribers`·`articles`)가 `lang.js`를 안 실어 `html lang="en"` 고정이고, 그래서 사이드바의 `t()`도 영어로 나온다. 한울님 요청: **한 어드민 안에서 언어가 일관되고, 한/영 전환 버튼이 있을 것.**

## 고칠 것

1. **별도 페이지 5개에 `lang.js` 로드** — `<script src="../lang.js?v=20260630">`를 `admin-nav.js` **뒤**(`dashboard.html`과 같은 순서). 각 페이지의 정적 텍스트에 `data-en/ko` 짝이 빠진 곳을 세어 **보고**(수는 세되, 이번엔 사이드바·상단 공통 요소만 짝을 채우고 페이지 본문 전수는 A-017·A-029 일괄 정리 때 — 범위를 넓히지 마라).
2. **사이드바 상단 한/영 토글** — `admin-nav.js`: 검색창 옆(또는 로고 아래)에 `KO | EN` 토글 버튼. 클릭 → `window.toggleLang()`(lang.js가 노출) → `lang.js`가 `localStorage['archinode-lang']`에 저장하므로 다른 어드민 페이지로 가도 유지된다. 토글 뒤 사이드바 라벨은 `data-en/ko` 짝이라 lang.js가 다시 훑어 바뀌고, 동적 요소(`t()`로 찍은 것)는 `adm_renderSidebar` 재호출로 갱신. `data-en/ko` 짝, 확인창 없음.
3. **초기 언어**: `lang.js`의 IP 자동 감지가 어드민에도 적용되면 해외 접속 시 영어가 된다 — 어드민은 **저장된 선택 > 기본 한국어**로 고정(`pickInitialLang` 흐름을 읽고, 어드민 페이지에서는 `<html lang="ko">` 기본 + 저장값 우선이 되게. `lang.js`는 공개 페이지 공통이라 **수정하지 마라** — 어드민 페이지 쪽 `html lang`·`data-langs` 속성으로 해결할 수 있는지 먼저 보고, 안 되면 `admin-core.js`에서 로드 직후 처리).
4. **캐시 스탬프** `?v=20260912c` → `?v=20260912d`(nav·core 변경).
5. 문서: 검수대장 A-035 `확인대기` + 이력. `CLAUDE.md` 3절 admin 설명에 "한/영 토글".
