## 배경 (처음 보는 사람용)

엑사 EX Works(`C:\이한울 작업 공간\EXA HOLDINGS\01 통합관리시스템\app\`)는 웹앱이지만 브라우저의 "앱 설치"로 바탕화면·작업표시줄에 깔리고 주소창 없는 전용 창으로 뜬다(PWA: `manifest` + 서비스워커). 아키노드 어드민도 같은 경험을 원한다. **엑사·매치보스의 규칙**: 서비스워커는 **아무것도 캐시하지 않는다**(계속 배포하는 단계라 캐시가 있으면 옛 화면이 남아 "새로고침해도 안 바뀐다"가 된다). 설치 가능 조건(HTTPS·manifest·서비스워커 등록)만 채운다.

## 고칠 것

1. **`admin/manifest.webmanifest`** (신규): `name` "ARCHINODE Admin", `short_name` "AN Admin", `start_url` `/admin/dashboard.html`, `scope` `/admin/`, `display` `standalone`, `background_color` `#f0f0f0`, `theme_color` `#111111`, `lang` `ko`, `icons`: 루트의 `android-chrome-192x192.png`·`android-chrome-512x512.png`(경로 `../android-chrome-…`, `purpose any`). **엑사 `app/manifest.*`를 먼저 읽고 형식을 맞춰라**(있으면).
2. **`admin/sw.js`** (신규, ~30줄): `install`에서 `skipWaiting`, `activate`에서 `clients.claim` + **기존 캐시 전부 삭제**, `fetch`는 **아무것도 가로채지 않는다**(핸들러를 두되 `event.respondWith` 없이 통과 — 설치 조건용 최소 워커). 주석에 "캐시 금지 — 엑사·매치보스 규칙, 정식 오픈 전" 명시. 엑사 `app/sw.js`(또는 상응 파일)를 읽고 그쪽이 쓰는 network-first 방식이 있으면 그대로 축약.
3. **어드민 6페이지** `<head>`: `<link rel="manifest" href="manifest.webmanifest">`, `<meta name="theme-color" content="#111111">`, `<link rel="apple-touch-icon" href="../apple-touch-icon.png">`. `admin/dashboard.html`(큰 파일 — Node 앵커 삽입, `</html>`·줄 수 확인).
4. **서비스워커 등록** — `admin/js/admin-core.js` 끝에 `if ('serviceWorker' in navigator) navigator.serviceWorker.register('sw.js', {scope:'/admin/'}).catch(…)` (별도 페이지는 `admin/` 안이라 상대경로 동일). 콘솔 오류 없이 실패는 `console.warn`만.
5. **설치 안내 버튼** — `admin-nav.js` 사이드바 맨 아래에 「앱으로 설치」 버튼(`beforeinstallprompt` 이벤트를 잡아 뒀다가 클릭 시 `prompt()`; 이벤트가 안 오면(이미 설치·미지원) 버튼 숨김). `data-en/ko` 짝. 확인창 없음.
6. **캐시 스탬프**: 어드민 6페이지 `?v=20260912b` → `?v=20260912c`(core·nav가 바뀌므로). 치환 개수 보고.
7. 문서: 루트 `CLAUDE.md` 3절 admin 설명에 "PWA 설치형(manifest·sw, 캐시 없음)", 8절 함정에 "서비스워커는 정식 오픈 전까지 캐시 금지(엑사 규칙)". `docs/ARCHINODE 규정집.md` 1-13절 끝에 한 줄 "어드민은 앱으로 설치할 수 있다(9월 12일)".
