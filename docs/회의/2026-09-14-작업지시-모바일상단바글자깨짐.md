# 작업지시서 — 모바일 상단바·탭바 글자 깨짐 4건 (A-014·A-037·A-038·A-039)

- **낸 사람**: 지휘 창 (26.09.14 아키 #1)
- **하는 사람**: node-white (Agent 도구 직접 호출 — 한울님 부재, 실행창 없음)
- **push·배포하지 않는다. 커밋(경로 지정)까지, 「배포 준비됨」.**
- 규칙 변경 없음.

## 배경

휴대폰(375px 안팎) 화면에서 공개 사이트·어드민·브랜드 포털 상단 영역의 글자가 세로로 쪼개지거나 옆으로 밀리는 문제가 네 곳에서 발견됐다(2026-09-12 브론즈 R6·R11, 검수대장 A-014·A-038·A-039). 더불어 로그인 계열 페이지 4개가 noindex 메타 태그 없이 로봇 파일만으로 검색 제외를 시도하고 있다(A-037). 넷 다 작고 서로 무관한 수정이라 한 지시서로 묶는다.

## 고칠 것

**1. A-014 — 공개 사이트 상단바 (High, 공개 페이지)**
`style.css` 모바일 미디어쿼리(247줄 부근)가 `.main-nav`만 숨기고 `.header-actions`(브랜드 로그인 링크)·`.logo-sub`("건축을 잇다")는 그대로 둬서, 375px에서 글자가 세로로 쌓이며 안내 띠를 덮는다. 실측: brands·request-consultation·magazine 등에서 `scrollWidth` 451(뷰포트 375보다 넓어 가로 스크롤 발생).
- `.header-actions` 안 브랜드 로그인 링크와 `.logo-sub`에 `white-space: nowrap` 적용, 필요하면 모바일 폭에서 `font-size` 축소 또는 로그인 링크를 아이콘/축약 텍스트로.
- auth-ui.js가 삽입하는 "Log In" 요소도 같은 규칙을 받는지 확인(동적 삽입이라 CSS 클래스 기준으로 잡을 것, JS 수정 아님).
- 완료 조건: 375px 폭에서 brands.html·request-consultation.html·magazine.html·index.html의 `document.documentElement.scrollWidth`가 375 근처(가로 스크롤 없음), 상단 글자가 한 줄 또는 자연스러운 줄바꿈으로 보임(세로로 쪼개지지 않음).

**2. A-038 — 어드민 상단바 (Medium, 로그인 뒤 화면)**
`admin/dashboard.html`(또는 `admin.css`) `.topbar .right` 요소가 `white-space: nowrap` 없이 모바일 미디어쿼리도 없어, 322px 폭에서 "브랜드 로그인"·"로그아웃" 글자가 세로로 끊겨 화면 위로 삐져나간다(`getBoundingClientRect` width 12~52px, top 음수 실측).
- `.topbar .right` 및 그 안 버튼/링크에 `white-space: nowrap` + 좁은 폭 미디어쿼리(필요하면 글자 축소나 아이콘화, A-014와 같은 방향으로 통일).
- 완료 조건: 322px 폭에서 상단바 요소가 화면 밖으로 안 나가고 겹치지 않음.

**3. A-039 — 브랜드 포털 탭바 (Medium, 로그인 뒤 화면)**
포털 `.tabs` 탭이 고정 `flex` 폭이라 좁은 화면에서 "제품"·"브랜드 매거진" 같은 글자가 세로로 쪼개진다.
- 탭에 `white-space: nowrap` + 좁은 폭에서 가로 스크롤 허용(`overflow-x: auto`) 또는 폭 축소 중 더 간단한 쪽으로. 새 기능 추가하지 말 것(탭 재배치 등은 범위 밖).
- 완료 조건: 좁은 화면에서 탭 글자가 안 쪼개지고 읽힌다(가로 스크롤 허용은 무방).

**4. A-037 — auth 페이지 noindex (Low, 공개 페이지지만 텍스트만)**
`auth/login.html`·`auth/signup.html`·`auth/profile.html`·`auth/reset-password.html` 4개 파일의 `<head>`에 `<meta name="robots" content="noindex,nofollow">` 한 줄씩 추가(이미 있는 `auth/token-entry.html` 패턴과 동일).

## 하지 말 것

- `git add -A` 금지 — 경로 지정(`style.css`, `admin/dashboard.html` 또는 `admin/admin.css`, 포털 CSS 파일, `auth/*.html` 4개 각각).
- `admin/dashboard.html`이 200줄 이상 바뀌면 Edit 통째 치환 금지 — CSS 블록 하나 추가/수정이면 보통 문제없지만, 줄 수를 스스로 확인할 것.
- 세 CSS 수정 모두 데스크톱(768px 이상) 레이아웃을 건드리지 않는다 — 모바일 미디어쿼리 안에서만.
- 4번(noindex)은 텍스트 한 줄 추가만, 페이지 다른 부분 수정 금지.

## 검증

- node-black 필수, CRITICAL 0.
- 375px·322px 등 좁은 폭 실측은 화이트가 브라우저 리사이즈로 직접 확인(로그인 없이 되는 A-014는 화이트가, 로그인 필요한 A-038·A-039는 로그인 정보 없으면 "확인 못 함"으로 남겨 브론즈에 넘긴다).
