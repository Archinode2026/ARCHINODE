# 카테고리 카드 사진 배정표 (A-379, 2026-11-09)

## 왜

카테고리 카드 제목이 **64종**인데 쓰던 사진이 **43장**뿐이라, 한 페이지 안에서
같은 사진이 다른 제목으로 나왔다(사진 쓰는 191파일 중 49곳, 그중 카테고리
10곳은 **나란한 두 카드**가 같은 사진). 섞어서 풀 수 없고 사진이 더 필요했다.

## 어떻게 골랐나

Unsplash 검색 페이지를 **내장 브라우저로 직접 열어** 실제 ID 를 뽑았다.
기억으로 ID 를 지어내지 않았다 — 기존 95장 중 3장이 이미 죽어 있던 일(A-372)을
되풀이하지 않기 위해서다. 고른 뒤 **20장을 한 장씩 실제로 불러 보아** 살아 있는지
확인했고, **6장이 죽어 있어 교체**했다. 죽은 것들은 전부 최근 ID 였다 —
Unsplash+(유료) 사진은 `images.unsplash.com` 으로 나오지 않는다. 쓰면 안 되는
것들이라 걸러진 것이 다행이다.

사진 설명은 Unsplash 의 alt 를 그대로 옮겼다(내가 본 것이 아니라 **출처가 적은 것**이다).
받은 뒤 모아보기로 눈으로 확인하고, 주제가 어긋나면 그때 바꾼다 — 「Toilets &」 자리에
고양이가 들어가 있던 일(A-378)이 있었다.

## 다음 단계

1. 승리님이 `tools\fetch-photos.ps1` 을 **다시 한 번** 돌린다 — 이미 받은 92장은
   건너뛰고 새 20장만 받는다.
2. 노드가 600·240 크기를 만들고, 위 표대로 카테고리 페이지의 `alt` 에 맞춰 넣는다.
3. 넣은 뒤 **한 페이지 안에서 같은 사진이 다른 제목으로 쓰이는 곳이 0인지** 다시 센다.

`Tiles & Ceramics`·`Toilets & Bidets`·`Washbasins Vanities`) 카드가 `object-fit: cover`
로 자르므로 문제되지 않는다(확인함).
