### 실측 확인된 문제

1. **[재현됨] 매거진 탭 콘솔 오류** — dashboard.html 로드 시 `TypeError: Cannot read properties of undefined (reading 'substring')` at `brand-portal/dashboard.html:1151`. 새로고침마다 재현(2회 확인). `loadArticles()` 가 각 글의 `content` 필드를 읽으려 하는데 실제 저장 필드는 `blocks`(배열)라 `undefined.substring()` 이 되어 던져짐. 이미 등록된 A-030(같은 코드 구간, XSS/이스케이프 관점)과 같은 자리지만 **다른 증상**(크래시) — 검수관리 등록 시 A-030 codeLocation과 연관 지어 별도 처리 필요할 수 있음(사람 판단 필요).
2. **[코드 검토, 미확인] 제품 등록 폼 한글 미지원** — `brand-portal/dashboard.html` 442~527행 "Add Product" 폼: Product Name/Collection/Description/Materials/Dimensions/Designer/Price Range 라벨과 옵션, "Submit for Review"/"Cancel" 버튼 등 대부분이 `data-en`/`data-ko` 없이 영어 하드코딩. Category·Subcategory 셀렉트만 이중언어 처리됨. 브랜드 포털은 언어 토글 UI가 안 보이지만 `lang.js` 로드되어 있어 한국어 IP/저장값이면 이 폼만 영어로 남는다. **화면 실측(한국어 상태) 필요** — 세션 충돌로 아직 못 함.
3. **[관찰, 범위 밖일 가능성]** "Access denied. Admin only." 경고가 콘솔에 남아있었는데, 이는 admin/dashboard.html 코드이고 이번 라운드 범위(brand-portal) 밖. 다른 라운드의 admin 접근 시도 잔여물로 추정 — 브론즈-C2 본인이 admin 페이지를 방문한 적 없음(네트워크 로그의 admin/js 요청은 세션 시작 이전 시점).
