## 측정 한계·내가 틀릴 뻔한 것

1. ★ **「`brands.html` 의 쉼표가 고쳐졌다」로 적을 뻔했다.** 라이브 화면에 쉼표가 **0건**이라
   그렇게 보였다. 그런데 라이브 코드는 옛 코드였고, **쉼표가 안 보이는 이유는 카테고리를
   2개 이상 가진 브랜드가 아직 없어서**였다. **「증상이 안 보인다」와 「고쳐졌다」는 다르다** —
   화면 대신 **기제**(`String(['a','b'])`)를 확인하고서야 갈렸다.
2. ★ **「`magazine.html` 은 이미 고쳐졌다」는 네 말을 그대로 받아 적을 뻔했다.** `git fetch` 를
   먼저 하고 보니 A-413 은 `bccda928`(**미푸시**)에 있고 라이브는 `995dc036` 이다.
   **작업본에서 고쳐진 것과 라이브에서 고쳐진 것은 다르다** — 네가 22차에 준 교훈 그대로다.
3. ★ **`auth/profile.html` 저장 제품 링크를 또 3/7 로 적을 뻔했다** — 22차와 같은 **0×0 허깨비
   줄상자**다. 이번에는 측정 함수가 미리 걸렀다(1px 미만 줄상자 제외). **교훈이 코드에 들어가니 안 당했다.**
4. **iframe 안에서는 `scrollIntoView` 도 `scrollTo` 도 안 먹는다**(`scrollY` 가 0 으로 남는다).
   → **iframe 자체를 키워**(390×1500~9000) 대상 요소를 iframe 의 시야 안으로 들이면 `elementFromPoint`
   가 제대로 돈다. 폭은 390 그대로라 미디어 쿼리는 유지된다. **iframe 검수의 스크롤 문제는 이걸로 푼다.**
5. **바깥 창의 진짜 휠(`computer{scroll}`)은 네 말대로 이벤트를 쏜다** — `.scroll-top.visible` 이
   붙는 것을 확인했다(scrollY 1000). 다만 **스크린샷을 먼저 찍어야** 좌표계가 잡힌다(두 번 걸렸다).
6. **`auth/profile.html` 의 브랜드 줄은 라이브에서 못 봤다 — 저장된 브랜드가 0건이다.**
   코드(`catText`)를 그대로 돌려 `Italy · Furniture · Lighting` 을 확인한 것뿐이다. 눈으로 본 것이 아니다.
7. **포털 사본의 한계**: `lang.js` 를 뗐으므로 ① `.lang-switch-btn` 이 없다(옛 `KR / EN` 링크가 남는다)
   ② JS 가 만드는 목록·오류·탭 전환은 못 본다 ③ 격자는 **내가 작업본 마크업을 끼워 넣은 것**이고
   실제 파일을 띄운 것이 아니다. **기하·CSS 는 진짜, 흐름은 못 믿는다.**
8. **`preview_start` 로 작업본을 띄울 수 없다** — 「no dev server on this surface」. 로컬 HTTP 서버도
   안 된다(이 셸은 승리님 기기의 localhost 에 못 닿는다). **미푸시 페이지는 fetch+iframe 이 유일한 길이다.**

   제목이 사진의 어느 부분을 가리는지는 푸시 뒤에 봐야 한다.
