- 한 번 `iframe` 으로 페이지를 끼우려다 CSP(`frame-src`)에 막혀 콘솔에 오류 1줄이 남았다 — 브론즈가 낸 것이지 사이트 결함이 아니다.

## 35차 (키보드와 읽어 주는 도구 — 공개 4화면)

노드가 띄웠다. 주제는 **「눈과 마우스를 안 쓰는 손님」**. 로그인·제출·쓰기 없음. 새 탭 `tab-7` 만 쓰고 닫았다

### 측정 조건 (먼저 밝힌다)
- 내장 브라우저가 **로그인된 상태**다(머리글에 계정 이메일·로그아웃 링크가 보인다) → 머리글 Tab 정거장이 비로그인보다 2개 많다.

- **건너뛰기 링크**: 4화면 모두 첫 Tab 에 「본문으로 건너뛰기」가 **보인다**(rect 0,0 150x44, 배경 rgb(28,37,51)·글자 흰색). Enter → URL `#main`, 초점이 `DIV#main` 으로 이동, **다음 Tab 은 본문 첫 요소**(홈 제외 3화면 「홈」 빵부스러기). 홈에서 확인한 첫 3정거장: 건너뛰기→로고→카테고리.

## 36차 (폼이 손님에게 무엇을 말하나 — 공개 6자리, 제출 없음)

노드가 띄웠다. 주제는 **「채운 뒤에 무엇이 보이나」**. 로그인·제출·쓰기 없음. 새 탭 `tab-8` 만 쓰고 닫았다
(`seed`·`tab-4`·`tab-5` 안 건드림). 제출 단추는 한 번도 안 눌렀다. 채운 값은 전부 비웠다(필드 길이 0 으로 재확인).

### 측정 조건 (먼저 밝힌다)
- 내장 브라우저는 **로그인된 상태**, 브라우저 언어는 **한국어**다. `validationMessage` 는 브라우저 언어를 따르므로 아래 한국어 문구는 이 브라우저의 값이다.
- 영어 모드는 `setLang('en')` 으로 바꿔 쟀고 끝나고 `setLang('ko')` 로 되돌렸다(`archinode-lang` = `ko` 재확인, 처음 값과 같음).
- **값을 JS 로 넣으면 `maxlength` 를 무시한다.** 그래서 글자 수 제한은 실제 키 입력(`type`)으로만 쟀다. JS 로 2,000자를 넣은 수치는 「한도 없음」의 증거일 뿐 한도 있는 칸의 증거가 아니다.
- 6자리 = `contact` · `sourcing-inquiry` · `request-consultation` · `list-your-brand` · `submit-trend` · 홈 뉴스레터. **`submit-trend.html` 은 폼이 0개**(「이제 매거진 글은 브랜드 포털에서 발행됩니다」 안내 쪽) → 잴 것이 없었다.

### 브론즈가 센 것 (멀쩡했다)
- **뉴스레터 영어 모드**: 한글 0건. contact·sourcing·list-your-brand 도 영어 모드 폼 본문 한글 **0건**.
- 오류 문구를 직접 쓰는 폼(sourcing·list-your-brand·뉴스레터·consultation)은 **언어를 따라가게** 짜여 있다(`ko`/`en` 분기, 소스 확인).
- 허니팟 칸(「Leave this field empty」)은 `aria-hidden`·`tabindex=-1` 안에 있어 낭독 대상 아님. 눈에 보이는 영어 아님.
- list-your-brand 의 처리방침 링크는 언어에 따라 `privacy.html` ↔ `privacy-en.html` 로 **바뀐다**. 푸터도 동일.
- 설명칸 카운터 「0/100 → 8/100」은 입력에 맞춰 즉시 바뀌고, 비우면 0/100 으로 돌아온다.

### 못 잰 것
- **제출 단추 `disabled` 를 실제로** 눌러서 본 것(금지). 소스로만 읽었다.
- 5,000자 한도(sourcing 메시지)에 **실제로 타이핑**해 넘기기(키 입력 5,000자는 안 했다). 이메일(254)·회사(200) 칸도 실입력은 안 했다.
- 영어 브라우저에서의 기본 검증 문구(브라우저가 한국어라서 한국어만 봄).
- 폼 제출 **뒤** 화면(성공·실패 문구) — 제출 금지.
- list-your-brand 의 JS 검증 문구(카테고리 선택 필수 여부 등)를 화면으로 본 것.
