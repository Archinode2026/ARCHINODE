# 브론즈 — 2026-11-13

## 34차 (비로그인 공개 길 — 검색 · 카테고리 · 제품 · 브랜드)

노드가 띄웠다. 주제는 **「물건을 보러 온 사람의 길」**. 폼은 제출하지 않았고 단추도 누르지 않았다
(검색창에 값을 넣어 본 것과 `localStorage` 의 언어 키를 바꿨다 되돌린 것이 전부).

### 측정 조건 (먼저 밝힌다)
- 내장 브라우저가 **로그인된 상태**다(머리글에 계정 이메일이 보인다). 그래서 Firestore 값은
  **토큰 없는 REST** 로 따로 쟀고, 화면은 로그인 상태에서 봤다. 화면 분기 중 비로그인 쪽
  (`openBimModal`·`toggleLike`)은 **코드 읽기**이고 눌러 보지 않았다.
- 새 탭 `tab-6` 만 썼다(`seed` 안 건드림). 쓰기·로그인·로그아웃 없음.
- 한 번 `iframe` 으로 페이지를 끼우려다 CSP(`frame-src`)에 막혀 콘솔에 오류 1줄이 남았다 — 브론즈가 낸 것이지 사이트 결함이 아니다.
- 「200% 확대」는 **뷰포트 559px 에뮬레이션**으로 갈음했다(글자 배율은 못 바꿈).

## 35차 (키보드와 읽어 주는 도구 — 공개 4화면)

노드가 띄웠다. 주제는 **「눈과 마우스를 안 쓰는 손님」**. 로그인·제출·쓰기 없음. 새 탭 `tab-7` 만 쓰고 닫았다
(`seed`·`tab-4`·`tab-5` 안 건드림). 실제 Tab·Enter·Esc 키를 눌러 쟀다(코드 읽기 아님).

### 측정 조건 (먼저 밝힌다)
- 내장 브라우저가 **로그인된 상태**다(머리글에 계정 이메일·로그아웃 링크가 보인다) → 머리글 Tab 정거장이 비로그인보다 2개 많다.
- 4화면 = 홈 `/` · `brands.html` · `categories/furniture.html` · `magazine.html`. 모바일 메뉴는 뷰포트 390px 에뮬레이션(끝나고 해제).
- 한 번 `eval` 로 측정 함수를 저장하려다 CSP(`unsafe-eval`)에 막혔고, 그 전에 `localStorage` 에 키 1개(`__bz_audit`)를 썼다가 **같은 호출에서 지웠다**(재확인: `null`). 사이트 결함 아님.
- 폼은 값을 채우지 않고 DOM 으로만 봤다.

### 0단계 — 기준선
라이브 푸터에 「0318」 **0건**(magazine 에서 확인) → 아직 **A-501 상태**. 기준선 그대로.

### 발견표

| 번호 | 화면이 말한 것 | 실제 (측정) | 판정 |

### 브론즈가 센 것 (멀쩡했다)
- **건너뛰기 링크**: 4화면 모두 첫 Tab 에 「본문으로 건너뛰기」가 **보인다**(rect 0,0 150x44, 배경 rgb(28,37,51)·글자 흰색). Enter → URL `#main`, 초점이 `DIV#main` 으로 이동, **다음 Tab 은 본문 첫 요소**(홈 제외 3화면 「홈」 빵부스러기). 홈에서 확인한 첫 3정거장: 건너뛰기→로고→카테고리.
  - 참고: `focus()` 로 억지 초점을 주면 링크는 화면 밖(x=-9999)에 남는다 — `:focus-visible` 일 때만 나타나는 것. 실제 키보드로는 나타남.
- **초점 표시**: 홈 24 · 브랜드 22 · 카테고리 22 · 매거진 22 정거장. 초점 테두리 **없는 자리 0**(예외는 N35-3 의 0높이 `#main` 1개뿐). 전부 `:focus-visible` 일치, 브라우저 기본 고리(`auto`) 또는 2.67px 고리. 홈 히어로 「브랜드 아티클 보기」 단추·머리글 이메일 링크는 눈으로 확인(크림색 고리 보임).
- **검색 가리개**: 열면 초점이 입력칸으로 이동. Tab 12번 → 정거장 `[검색 단추 · × · 입력칸]` 3개를 4바퀴, **밖으로 샌 것 0**. `role=dialog`·`aria-modal=true`. **Esc** 로 닫힘(`display:none`), 초점이 **열기 전 자리(Search 단추)로 복귀**.
- **모바일 메뉴 Esc**: Esc 로 닫히고 초점이 토글로 돌아온다.
- **그림 대체글**: `alt` 속성 **아예 없는 것 0장**(홈 46 · 브랜드 1 · 카테고리 9 · 매거진 131). `alt=""` 는 홈 **43장** — 41장은 글자 있는 링크 안(장식), 2장은 `photo-band`·`cta-photo` 배경 사진(장식). **이름 없는 링크/단추 속 빈 alt 0**. 홈 나머지 3장은 alt 가 「Architecture」「Interior Design」「Design」 한 단어(내용 설명은 아님, 낮음).
- **단추인 척하는 것**: `onclick` 달린 `div`·`span`·`li` 등 **0**. `a[href="#"]` 는 3개(언어 `English`·`한국어` + 로그아웃)인데 모두 실제 `<a>` 라 키보드로 눌린다(로그아웃은 `aria-label` 있음). 언어 메뉴 패널은 닫힌 동안 `display:none`.
- **폼 이름표**: 공개 4화면에서 이름표 없는 필드 = 홈·매거진 뉴스레터 허니팟 `input.hp_newsletter` 1개(숨김 함정, 눈에 안 보이게 설계) + 구글 reCAPTCHA 가 심은 `textarea#g-recaptcha-response-*` 1개(외부). **사이트가 쓴 보이는 필드 0**. 브랜드·카테고리는 필드 없음.

### 못 잰 것
- 실제 스크린 리더(낭독) — 이름·역할 낭독 내용은 못 들었다. DOM 속성으로만 봤다.
- 초점 고리의 **대비비**(숫자). 색값만 적었고 N35-2 는 눈 판단.
- 비로그인 머리글의 Tab 정거장 수(로그인 상태로 쟀다).
- 영어 모드의 건너뛰기 링크 문구·`lang` 속성, 언어 메뉴 패널을 키보드로 여는 길.
- 공개 폼 페이지(`contact`·`sourcing-inquiry` 등)의 필드 — 주제가 4화면이라 안 갔다.
