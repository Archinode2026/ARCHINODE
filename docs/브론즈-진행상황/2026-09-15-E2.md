## 1. A-053 / A-055 재검증 (어드민 사이드바, 모바일)

- **A-053(데스크톱 세로 축소·마우스 휠)**: 이번 라운드에선 재검증하지 않음(지시서 우선순위상 A-055/모바일에 집중). 기존 판정(확인대기, A-017 사람 재확인 요청 대기) 유지.
- **A-055(모바일 폭, 메뉴 펼침 상태) — 재검증 결과: 평가 상향 필요**. 375×700 뷰포트로 어드민 로그인 상태에서 "Menu" 버튼을 눌러 사이드바를 펼친 뒤 JS로 직접 측정:
  - `sidebar.scrollHeight` = 867, `sidebar.clientHeight` = 600(= `calc(100vh - 100px)`, A-053 처방이 그대로 적용된 값), `computedOverflow` = `hidden`.
  - 각 메뉴 항목의 좌표를 측정한 결과 "Articles(Cards)"·"Notices"·"Activity Log"·"Review Board"·"Regulations"·"Settings" **6개 항목이 전부 `visible:false`** — 스크롤도, 페이지 자체 스크롤도, 화면 확대도 이 항목들을 보이게 하지 못함(overflow:hidden이라 사이드바 박스 자체가 그 높이에서 잘림).
  - 뷰포트를 더 키워도(예: 800px 높이) `max-height`는 `calc(100vh-100px)`=700이라 필요한 867px에는 못 미쳐 대부분의 실제 휴대폰 화면에서 상시 재현될 것으로 판단.
  - 원래 검수대장 기재("지금은 실해 없음, 잠재적 재발 위험만")는 **낡은 평가**로 확인 — 지금 당장 실제로 6개 메뉴 진입이 불가능한 상태.
  - 검수대장 A-055 행에 이력 갱신 + 검수관리 탭에 **A-040**으로 신규 등록(실측 수치 포함).

## 2. A-056 재확인 (reset-password.html)

- 코드 확인: `auth/reset-password.html` 16~17행에 `firebase-app-compat.js`·`firebase-auth-compat.js`만 있고 `firebase-firestore-compat.js` 없음. `firebase-config.js:30` `const db = firebase.firestore();`는 A-001(auth)과 달리 무가드.

- 검수대장 A-056 행에 이력 갱신 + 검수관리 탭에 **A-039**로 신규 등록.
