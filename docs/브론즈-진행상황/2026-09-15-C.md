- 제품 좋아요(하트) 실측 — 라이브에 승인된(approved) 제품이 현재 0건이라 클릭해볼 대상이 없음. 브랜드 좋아요와 동일한 규칙 패턴이라 코드상 같은 결함 예상(A-032 techNote에 명시)
- 브랜드 Inbox 상태 "진행중 전이" 실측 — 기존 리드가 이미 R11에 의해 Closed(종료, 의도적으로 되돌릴 수 없음)라 전이 버튼을 실제로 눌러볼 대상이 없었음. 코드 확인으로 설계 자체는 이상 없음을 확인
