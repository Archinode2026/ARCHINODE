## 1. 가장 큰 질문 — **브랜드가 1개인 디렉터리에 왜 €10 을 내나**

이걸 먼저 풀지 않으면 나머지는 숫자 놀음입니다.

지금 사이트가 주는 답은 「쇼케이스에 실립니다」인데, **그 쇼케이스를 보는
사람이 아직 없습니다.** 유럽 브랜드는 바보가 아니라서 들어와 보면 압니다.

**제가 제안하는 답: 구독이 파는 것은 「자리」가 아니라 「기록」입니다.**

> 매달, 당신 품목에서 **한국 전문가가 무엇을 찾았는지** 알려 드립니다.
> 건축사 몇 명, 인테리어 몇 명, 딜러 몇 명이었는지도요.
> 그중 **우리가 못 보여 드린 것**이 무엇인지도 알려 드립니다.

**같은 €10 인데 파는 물건이 다릅니다.**
디렉터리 자리가 €10 이면 **비쌉니다**(아무도 안 보니까).
한국 수요 기록 한 장이 €10 이면 **쌉니다**(그 정보를 다른 데서 못 삽니다).

그리고 이건 **지금 당장 참말**입니다 — 브랜드가 1개여도, 매거진 130편으로
들어온 한국 전문가가 무엇을 찾았는지는 기록할 수 있습니다. 어제 지은
어드민 「한국 수요」 리포트(A-661)가 바로 그 기계입니다.

## 2. 사다리 — 유럽 브랜드가 올라가는 순서

손님이 **사는 순서**대로 세웠습니다. 「실어 주세요」가 아니라
**「우리가 한국에 들어갈 수 있나」**가 첫 질문이기 때문입니다.

### S0 — 진단 · **무료**

| | |
|---|---|
| 브랜드가 묻는 것 | 「우리 품목이 한국에 들어갈 수 있나?」 |
| 받는 것 | ① 인증 대상 여부(KC·KS·환경표지) ② 리드타임 ③ **법인 없이는 수입통관 주체가 없다**는 사실과 그 해법 ④ 기존 한국 딜러 확인 |
| 왜 무료인가 | **이게 우리의 자격 증명입니다.** 대행사는 이 답을 못 합니다. 한 번 받아 보면 나머지가 팔립니다. 돈을 받을 만큼 긴 일도 아닙니다 |

### S1 — 가입(등재) · **무료 · 심사 있음**

| | |
|---|---|
| 받는 것 | 브랜드 페이지 · 문의 폼 · 포털 계정 · 매거진 연결 |
| **제안: 「3개월 무료」를 없앱니다** | 지금은 시계를 겁니다. 손님은 **「3개월 뒤에 돈 내라」**만 듣고 **「왜 내야 하나」**는 못 듣습니다. 브랜드 1개짜리 디렉터리에서 시계는 압박이 아니라 **불안**입니다. 가입은 그냥 무료로 두고, 돈은 S2 에서 **값을 보여 주고** 받습니다 |

### S2 — 구독 · **€10/월 또는 €100/년**  ← **여기가 핵심**

받는 것 넷:

| | 무엇 | 지금 가능한가 |
|---|---|---|
| ㄱ | **내 품목의 한국 수요 리포트 — 매달** (문의 수 · 품목별 · 추이) | **네** — A-661 이 집계합니다 |
| ㄴ | **내 품목에서 「찾았는데 없었던 것」** (0건 검색) | 수요증거 설계 2단계 — **처리방침 갱신 뒤** |
| ㄷ | 나에게 온 문의 전부 + 내 품목 문의 **합계**(남의 문의는 내용 없이 수만) | 포털이 이미 `brandId` 로 리드를 보여 줍니다 |
| ㄹ | 브랜드 페이지 상단 노출 · 매거진 기사 연결 | 네 |

**ㄱ 하나만으로도 €10 의 값이 섭니다.** 나머지는 덤입니다.

### S3 — 건당 서비스

| 무엇 | 지금 값 | 비고 |
|---|---|---|
| 딜러 스크리닝 (온라인) | EUR 100 | 그대로 |
| 딜러 스크리닝 (대면 보고서) | EUR 1,000 | 그대로 |
| 딜러 모니터링 | **값 없음** | ★ 정하셔야 합니다 |
| 인증 지원 | **값 없음** | ★ 정하셔야 합니다 |
| 컨설팅 | EUR 280 / 1,000+ | 그대로 |

### S4 — 박람회 진출 · **사이트에 아직 없습니다**

지난번 S0~S5 설계가 여기 들어옵니다(통관 주체 · 전시 반입 · 부스 · 현장 · 뒤처리).
**가장 큰 돈이 여기이고, 지금은 컨설팅의 「Other / Custom」 안에 묻혀 있습니다.**

## 3. 「가입」과 「구독」을 가를까

| | 가르지 않는다 (지금) | **가른다 (제안)** |
|---|---|---|
| 가입 | 신청 = 3개월 무료 구독 시작 | **무료 · 기한 없음** — 페이지·문의 폼 |
| 구독 | 3개월 뒤 자동으로 €10 | **원할 때 켠다** — 수요 리포트를 받기 위해 |
| 손님이 듣는 말 | 「3개월 뒤에 돈 내세요」 | 「무료로 들어와 보세요. 한국이 당신 품목을 얼마나 찾는지 보고 싶으면 €10」 |
| 우리가 얻는 것 | 3개월 뒤 이탈 | **브랜드 수가 먼저 늘고**, 리포트에 값이 생기면 전환 |

**저는 가르는 쪽을 권합니다.** 지금 우리에게 급한 것은 €10 이 아니라
**브랜드 수**입니다(디렉터리가 1개입니다). 무료 가입으로 수를 늘리고,
수요 기록이 쌓이면 그때 구독이 저절로 팔립니다.

## 4. 디지털 상품 — 방향을 가릅니다

지금 하나의 이름 안에 **두 가지**가 섞여 있습니다.

### ㄱ) 한국 전문가에게 파는 것 — **그대로 둡니다**

EUR 29~49/건 · 다섯 분류(트렌드 리포트 · CAD · BIM · 스펙시트 · 시장자료).
**이건 바이어 쪽을 돈으로 바꾸는 유일한 라인**이고, 핵심코어의 고리에서
「바이어 쪽은 자산」이라는 결정과 어긋나지 않습니다 — 자산을 **파는 것이
아니라**, 자산을 모으는 과정에서 나오는 부산물을 파는 것이니까요.

### ㄴ) 유럽 브랜드가 받는 혜택 — **여기를 새로 세웁니다**

지금은 「기여하면 크레딧」 한 줄뿐입니다. 크레딧은 혜택이 아니라 **인사**입니다.
제안하는 혜택 둘:

| 혜택 | 무엇 | 왜 센가 |
|---|---|---|
| **① 내 파일을 ARCHINODE 형식으로 올린다** | 구독 브랜드는 자기 제품의 스펙시트·CAD·BIM 을 한국 규격 대조(KS·KC)와 함께 올릴 수 있다 | 한국 설계사무소가 쓸 수 있는 꼴로 바꿔 주는 일을, 브랜드는 혼자 못 합니다 |
| **② 누가 받아 갔는지 알려 준다** | 그 파일을 내려받은 사람의 **직군과 건수**(이름이 아니라 수) | ★ **한국 건축사 N명이 내 BIM 파일을 받아 갔다** = 내 제품이 도면에 들어갔을 수도 있다는 가장 가까운 증거입니다. 어떤 디렉터리도 이걸 못 줍니다 |

### ㄷ) 유럽 브랜드가 **사는** 디지털 상품도 하나 있어야 한다면

**시장자료(market-intel)** 입니다 — 「한국 인테리어 시장 브리프」 같은 것.
유럽 브랜드가 €29 에 사는 게 자연스럽고, 다섯 분류에 **이미 있습니다.**
그리고 이건 S0 진단으로 이어지는 **가장 싼 첫 접점**입니다.

                                        S3 건당 서비스        디지털 상품 기여

                                        인증 지원 ?           누가 받았는지)

S3·S4 를 살 이유가 생깁니다.
