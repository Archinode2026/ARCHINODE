## 4. 확장용 유틸 (A-177에서 꺼내 둠, 아직 미사용)

섹션에 클래스 하나만 얹으면 메인과 같은 리듬이 된다.

```html
<section class="band-beige band-pad">
  <div class="container">
    <h2 class="band-title">…</h2>
    <a class="band-tile"><img …></a>
  </div>
</section>
```

`.band-white` `.band-beige` `.band-grey` / `.band-pad` `.band-pad-sm` / `.band-title` / `.band-tile`

밴드 순서는 메인 기준 **화이트 → 베이지 → 화이트 → 연그레이** 반복.

## 5. 넓힐 때 걸리는 것 — 반드시 먼저 읽을 것

실측 기준(전체 HTML 247개):

### (1) style.css 를 **아예 링크하지 않는 페이지 14개**
```
privacy-en.html
admin/articles.html  admin/bim-requests.html  admin/consultations.html
admin/newsletter-subscribers.html  admin/notify-subscribers.html  admin/trend-submissions.html
auth/login.html  auth/profile.html  auth/reset-password.html  auth/signup.html  auth/token-entry.html
brand-portal/dashboard.html  brand-portal/login.html
```
토큰도 리디자인도 **전혀 닿지 않는다.** 여기는 개별 수정이거나, `style.css` 를 링크한 뒤 충돌을 정리하는 작업이 선행돼야 한다.

### (2) `<link style.css>` **뒤에** 인라인 `<style>` 이 오는 페이지 148개
같은 명시도면 **인라인이 이긴다.** 그래서 메인 작업 내내 선택자에 `body` 를 붙여야 했다.
- `.footer` 를 이기려면 `body .footer`
- 인라인이 `.footer-col ul li a`(0,1,3)면 `body .footer .footer-col ul li a`(0,2,4)까지
- `.nav-cta` 처럼 `!important` 가 박힌 건 **같은 무기**로만 이긴다

### (3) 인라인 `:root` 로 토큰을 덮는 페이지 4개
`index.html` `magazine.html` `trend-report.html` `request-consultation.html`
→ 토큰을 바꾸면 **이 4개도 같이 고쳐야 한다**(A-164·A-169에서 두 번 겪음).

### (4) 요소에 직접 박힌 `style=` 속성 1,504개
스타일시트로는 못 덮는다(`!important` 아니면). 페이지를 손볼 때 같이 걷어내는 게 맞다.
많은 순서: `for-brands`(44) `contact`(39) `list-your-brand`(38) `brands/view`(36) `submit-trend`(36) `products/view`(26)

### (5) 같은 파일 안에서 **뒤쪽 규칙이 앞쪽을 덮는 함정**
메인 작업 중 네 번 발생했다. 새 규칙을 "덧붙이지" 말고 **뒤쪽 원본을 직접 고쳐야** 한다.
`!important` 끼리 부딪혀도 뒤가 이긴다.

## 7. 검증 방식 (메인에서 쓴 것 그대로)

폭 8~11개(1920~360px)에서 매번 확인한 항목:
- 가로 스크롤 0 / 뷰포트 넘치는 요소 0 (가로 스크롤러 내부는 예외로 분리)
- 페이지 에러 0
- 대비비 AA(작은 글자 4.5:1) — **배경 추적이 사진을 못 보므로 사진 위 텍스트는 오탐**. 토큰 단위로 따로 잰다.
- 적용 전/후 같은 조건 비교로 "원래 있던 문제"와 "내가 만든 문제"를 가른다

## 8. 미해결로 남은 것

- **A-165** `--gray-400`(2.19:1) `--gray-500`(3.01:1) 이 크림 배경에서 AA 미달. 어두운 배경에서도 쓰여 전역 수정 불가 — 밝은 배경용/어두운 배경용 분리 필요.
- **A-167** 매거진 글 생성 파이프라인의 이중 이스케이프 원인 미확인(새 글에서 재발 가능).
- **A-171** style.css 미링크 14개 페이지를 공통 스타일로 끌어오는 작업.
- 제품 타일은 사진만 있다. 실제 제품이 들어오면 카드 구조로 교체(마크업에 주석 표시).
- 한국 네트워크 섹션의 파트너 로고 자리 — 승리가 로고 파일 제공 예정.
- 브랜드 입점 우측 사진 — 승리가 브랜드 사진 제공 시 교체.
