# 리드의 어드민 전용 기록 옮기기 (A-481) — 1회성

**왜:** 배정된 브랜드는 `leads` 문서를 **통째로** 읽는다(그래야 포털 인박스가 돈다).
그 문서에 `adminNote`(어드민 메모 1000자)와 `history[]` 의 어드민 줄
(`by` = 어드민 이메일, `note` = 어드민이 쓴 상태 메모)이 들어 있었다.
Firestore 에 필드 단위 읽기가 없으니 「화면에 안 그린다」로는 가려지지 않는다.

**새 자리:** `leads/{id}/internal/admin` — 어드민만. 본문서 `history[]` 의 어드민 줄은
**뼈대만** 남긴다(`status` · `at` · `byRole`). 브랜드가 남긴 줄은 그대로 둔다.

**순서:** ① 규칙 게시 → ② 아래 1회 실행. 규칙 게시 전에는 `internal` 쓰기가 전부 거부된다.
(코드는 이미 새 자리를 읽고 쓴다. 안 옮긴 문서는 어드민 메모가 빈 칸으로 보일 뿐이고,
읽기에 실패하면 **빈 값으로 덮어쓰지 못하게** 칸이 잠긴다.)

## 콘솔에서 1회 실행 (어드민으로 로그인한 `/admin/dashboard.html` 에서)

```js
(async () => {
  const snap = await db.collection('leads').get();
  const log = [];
  for (const d of snap.docs) {
    const x = d.data() || {};
    const hist = Array.isArray(x.history) ? x.history : [];
    const priv = hist.filter(h => h && h.byRole === 'admin' && (h.by || h.note))
                     .map(h => ({ status: h.status || '', by: h.by || '', at: h.at || '', note: h.note || '' }));
    const slim = hist.map(h => (h && h.byRole === 'admin')
      ? { status: h.status || '', at: h.at || '', byRole: 'admin' } : h);
    const payload = {};
    if (x.adminNote) payload.adminNote = x.adminNote;
    if (priv.length) payload.notes = priv;
    const hadKey = Object.prototype.hasOwnProperty.call(x, 'adminNote');
    if (!Object.keys(payload).length && !hadKey) { log.push({ id: d.id, 결과: '옮길 것 없음' }); continue; }
    // 1) 먼저 옮겨 심는다
    if (Object.keys(payload).length) {
      await d.ref.collection('internal').doc('admin').set(payload, { merge: true });
      // 2) 되읽어 확인한 다음에만 본문서를 정리한다
      const c = await d.ref.collection('internal').doc('admin').get();
      const got = c.exists ? (c.data() || {}) : {};
      const ok = (!payload.adminNote || got.adminNote === payload.adminNote)
              && (!payload.notes || (Array.isArray(got.notes) && got.notes.length >= payload.notes.length));
      if (!ok) { log.push({ id: d.id, 결과: '★중단 — 확인 실패, 본문서 그대로' }); continue; }
    }
    const upd = { history: slim };
    if (hadKey) upd.adminNote = firebase.firestore.FieldValue.delete();
    await d.ref.update(upd);
    log.push({ id: d.id, 결과: '정리 — 어드민메모 ' + (hadKey ? 'O' : 'X') + ' · 어드민줄 ' + priv.length + '건' });
  }
  console.table(log);
  console.log('끝. 「★중단」 이 있으면 노드에게 그 줄을 알려 주세요.');
})();
```

- 한 번 더 실행해도 안전하다(옮길 것이 없으면 그냥 넘어간다).
- 값을 콘솔에 찍지 않는다 — 기록은 `internal/admin` 자체다.

## 확인

1. 어드민 → 고객 > 리드 인박스 → [보기]: **어드민 메모**와 **이력**(어드민 줄에 이메일·메모)이 전과 같이 보이는지.
2. 상태 변경 한 번 → 이력에 한 줄 늘고, 메모 본문이 보이는지.
3. 브랜드 포털 인박스 → [보기]: 이력의 어드민 줄이 **「ARCHINODE」** 로 보이고 **메모 본문이 없는지**.
4. 로그아웃/브랜드 계정 콘솔에서 배정된 리드를 읽어 `adminNote` 가 **없고**
   `history` 의 어드민 줄에 `by` · `note` 가 **없는지**.
