> 지나가며 어휘 불일치를 찾았습니다 — 어드민 수요 리포트의 업종 지도에

### A-671 — 어제 주석 걷기가 목적을 반만 달성했습니다 (브론즈 54차가 잡음)
HTML 주석은 실제로 걷혔는데, 같은 파일의 `<style>`·`<script>` 안 `/* */` 에
**6.2배(21,669자)** 가 남아 있었습니다. 걷어내려던 바로 그 내용이 거기
있었습니다 — 법률 미결 표시, 사람 이름 네 곳, 「거짓말」.
**제 주장은 참이었고 목적은 미달이었습니다.** 브론즈 판정이 맞습니다.

여덟 쪽 주석 **25,154자 → 9,574자**. 공통 파일은 **금칙어가 든 주석만** 골라

뒀습니다. 「코드가 왜 이 모양인지」는 지워서는 안 되는 것입니다.

> 중간에 **제 시험이 제 과잉 삭제를 잡았습니다.** `digital-products.html` 의
> 2,367자 주석이 「★ 상품을 올리려면 여기만 고치시면 됩니다. 아래 틀을 복사해

### A-675 — 「13번 따로 고쳤다」의 진짜 원인
`privacy-en.html` 을 공용 CSS 로 바꾸려고 열었는데 **진단이 틀렸습니다.**
CSS 중복이 아니라 **옛 세대 쪽 틀**입니다 — 꼬리말·검색·맨위로의 마크업 낱말이
지금 틀과 다릅니다. 그래서 `style.css` 가 닿지 않고, 쪽 CSS 20,794자로 자기
꾸밈을 따로 듭니다(변수 대신 하드코딩, 컨테이너 폭도 다름).
전역 수정 **A-206·A-630·A-641·A-648·A-652 가 전부 이 쪽을 비껴간 이유**입니다.

**CSS 삭제가 아니라 쪽을 다시 짜는 일**이고, 법률 쪽이라 브라우저 실측이 필요해서
**밤에 혼자 하지 않았습니다.** 한 마디만 주시면 하겠습니다.

## 보고 쓴 뒤 — 브론즈 55차와 브라우저 실측 (A-676 ~ A-679)

푸시가 미뤄져 라이브로 못 재니, 브론즈를 **저장소를 직접 읽게** 보냈습니다.
**제 실수 다섯을 잡아 왔습니다.**

| 브론즈가 잡은 것 | 처리 |
|---|---|
| **「운영자과」 3곳** — 「승리님과」를 기계로 바꿔 **조사가 깨졌습니다** | 「운영자와」로 고치고 다른 조사까지 전수 확인 |
| **제 검사기가 기준을 반만 적용** — 문 링크에는 보이는 글자를 국문으로 강제하면서 `class="tag"` **103편**은 영문 폴백으로 통과시켰습니다 | 103편 맞추고 검사로 못 박음 |
| 문이 **없는 파일**을 가리켜도, `?topic=` 이 허용 옵션이 아니어도 통과했습니다 | 검사 둘 추가 |
| 새 검사기 둘에 **자기 시험이 없었습니다** | 13건·5건 신설 |
| `check-all` 이 「이 아홉은」인데 브라우저 검사는 10항목 | 고침 |

> 그리고 **제 깨기 시험이 저장소를 더럽혔습니다.** 검사를 쪼개 돌릴 때 `timeout`
> 이 시험을 중간에 죽여 기사 하나가 깨진 채 남았습니다 — **다음 실행에서 제 검사가
> 그걸 잡았습니다.** 두 시험에 죽어도 되돌리는 손잡이를 달고, 실제로 죽여서
> 해시가 돌아오는 것을 확인했습니다.

**브라우저 실측** (컨테이너에 저장소를 가져가 재었습니다 — 브론즈 기계에는 크로미움이 없었습니다):

- **A-676** — 좁은 폭 검사 표본에 **매거진 기사가 한 쪽도 없었습니다.** 130편이고
